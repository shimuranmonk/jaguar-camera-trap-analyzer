# Analysis Data worksheet

Analysis Data supplies one row per exported image. Separate exif_ and ocr_ columns preserve the two sources for immediate filtering, pivot tables, and custom analysis. The sheet uses the latest attempt for each source independently, includes processing status and record/run identifiers, and does not silently substitute an older successful attempt when the latest attempt failed.

Normalized EXIF fields include timestamp, timezone availability, manufacturer, model, serial identifier, temperature in Celsius, latitude, longitude, dimensions, and orientation when available. Every raw EXIF tag present in the selected latest records receives an exif_raw.Group:Tag column. These columns retain ExifTool's numeric codes and original units; structural pointer tags absent from extraction cannot be recovered by the exporter.

OCR columns include printed timestamp/date/time, camera/site label, brand, Fahrenheit and Celsius readings, timezone availability, recognized text, minimum token confidence, profile/version, warnings, and review status. The first temperature candidate per unit supplies its numeric column, accompanied by a candidate count. All candidates and tokens remain in the existing evidence sheets.

Column availability for camera-specific raw tags follows the selected image set. Missing values remain blank. Long strings continue in additional __part_N columns without adding image rows. Excel's column limit produces a clear export error rather than dropping tags. Existing export scope, stable image IDs, source histories, text protection, and non-overwrite behavior remain in force. GPS and other private metadata belong to the local workbook rather than the repository.
