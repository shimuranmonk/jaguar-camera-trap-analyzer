# Dashboard design direction

The supplied AddaxAI dashboard image establishes the layout pattern: persistent sidebar, project context, filter strip, compact KPI tiles, larger chart cards, progress/review panels, and a clear export action. Its assets and example statistics are not adopted.

The initial JAGUAR palette uses a pale blue-gray canvas (#EFF4F6), soft near-white cards (#F8FBFC), dark slate text (#263D49), muted teal emphasis (#245C65), and subdued teal progress bars (#6E9FA5). Borders use cool gray (#D3DFE4). The scheme avoids large saturated areas and stark white backgrounds while retaining readable labels. Individual comfort still depends on screen brightness and viewing conditions.

The current dashboard queries local SQLite data for logical images, available paths, additional duplicate paths, EXIF extraction coverage, remaining EXIF work, and latest extraction failures. Metadata coverage reports a count and explicit denominator; available file formats and import status are shown alongside it. The export action remains disabled until export implementation. Later camera/date/run filters require their corresponding stored fields and workflow gates.

Species rankings, trap-night statistics, activity interpretations, maps, and capture events remain excluded from MVP 1. Animal/person/vehicle results and review progress will appear only after those processing stages exist. A missing value never becomes a fabricated zero-result analysis.
