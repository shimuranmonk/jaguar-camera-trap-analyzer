# ExifTool setup

Gate 3 requires a separately installed or portable ExifTool executable. The Processing page accepts its location; the optional JAGUAR_EXIFTOOL environment variable supplies the initial field value. The portable executable and its companion exiftool_files folder must remain together. No network access is needed during image extraction.

The local validation used ExifTool 13.59 from the Windows package maintainer. Source locations and licensing references are available at the [official ExifTool site](https://exiftool.sourceforge.net/) and the [Windows package maintainer](https://oliverbetz.de/pages/Artikel/ExifTool-for-Windows). Bundling and redistribution require separate packaging review.

Processing starts or resumes a compatible paused run. After completion, another extraction creates a new run and retains previous records. A changed tool or normalizer version starts separate history. Import and EXIF work share a project writer lock; one processing stage runs at a time. Failed source files can be imported again before a fresh EXIF run.

All extraction calls use fixed reading arguments, disable external ExifTool configuration loading, and enforce a timeout. Camera models, serials, GPS, temperatures, and timezones remain missing when evidence is absent or invalid. EXIF data does not substitute for image-overlay OCR.
