# Gate 5 evidence

Gate 5 adds the MIT MegaDetector V6 compact adapter through PyTorch-Wildlife 1.3.0, a Detection processing tab, and durable accepted boxes in migration 5. Each result stores class, score, normalized xywh coordinates, exact weight hash, threshold, device, batch size, and fallback information. Animal/person/vehicle classes can overlap within an image. Empty accepted-box lists are explicitly no_accepted_detection, never confirmed blank.

Local CPU inference processed all seven supplied photographs without execution failures at threshold 0.2 and batch size one. Four photographs produced accepted animal detections and Human.JPG produced a person detection. Humes Wheater.JPG and Arabian Tahr 2.JPG produced no accepted detections despite visible animals. These are recorded model misses requiring human review, not successful animal-identification claims. No vehicle or confirmed-blank originals were supplied, so real optical coverage for those cases remains outstanding. CPU inference was exercised; CUDA initialization/inference fallback is implemented but the installed CPU runtime could not exercise real GPU behavior.

The local automated suite passed 49 tests, including class/score/coordinate validation and threshold rejection. Prior OCR, source integrity, resume, migration, and desktop checks remain passing. Dependency checking reports no broken requirements after alignment of OpenCV 4.10 variants and the slicing helper. Some upstream modules import unused audio/web dependencies; the pinned runtime includes those imports without exposing audio, web, or cloud features in JAGUAR.
