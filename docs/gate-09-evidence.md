# Gate 9 — Windows packaging preview

The packaging source assembles an isolated embedded Python 3.13 runtime, PySide6 application, CPU inference dependencies, local OCR and MIT MegaDetector assets, and ExifTool. A small PyInstaller launcher starts the embedded interpreter so spawned processing workers use the same installed runtime. An Inno Setup definition targets a per-user 64-bit Windows installation.

The assembled runtime passed 63 automated tests. The packaged launcher completed its offscreen startup check with exit code zero. Actual bundled OCR recovered the Sandgrouse overlay timestamp, and the bundled detector accepted the Human photograph as a person. Both engines used the embedded application and local models. The bundle retains the application license, package license files, a dependency inventory, and model/runtime asset hashes. Original photographs, project databases, and private metadata are excluded from repository and installation sources.

The preview includes upstream transitive packages with additional license obligations, including AGPL components. Selection of MIT MegaDetector weights does not establish redistribution clearance for the entire dependency tree. Public release remains pending a complete license/source inventory and redistribution decision. No code-signing or fresh-machine compatibility result is claimed.
