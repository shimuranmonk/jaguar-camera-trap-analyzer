# Frozen MVP 1 baseline

The controlled development handover dated 24 October 2026 establishes JAGUAR as an offline-first Windows camera-trap extraction and reporting application. This record summarizes that baseline; the supplied handover remains the detailed reference.

The approved pipeline recursively discovers JPG, JPEG, JFIF, and PNG images, preserves originals, identifies duplicates by SHA-256, retains raw ExifTool and PaddleOCR observations, reconciles metadata with provenance, stores MegaDetector V6 animal/person/vehicle detections, supports audited human review, and exports a documented multi-sheet Excel workbook. SQLite stores migrations, processing checkpoints, run histories, errors, and review state. Physical cameras and deployments remain distinct identities.

The architecture uses PySide6, isolated inference workers, CPU fallback, hardware-aware batching, and later PyInstaller one-folder/Inno Setup packaging. A 5,000-plus-image acceptance workload follows smaller benchmarks on original mixed-brand images.

Species classification, video, cloud services, multi-user accounts, ecological analytics, maps, trap-night statistics, and capture-event grouping remain excluded. Zero accepted detections never establishes a confirmed blank image.

The dashboard follows the approved AddaxAI-inspired information architecture, with real stored metrics and clearly labeled missing states. The separate screenshot and representative original photographs remain outstanding.

The implementation sequence is foundation, ingestion, EXIF, OCR, detection, reconciliation/review, dashboard/workers, Excel export, packaging, and acceptance/recovery. Each gate requires evidence and a client decision before the next begins. Proposed schema details, field tolerances, OCR coverage, final workbook columns, and asset redistribution require review at their relevant gates.
