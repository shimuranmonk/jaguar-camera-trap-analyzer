# The JAGUAR preview guide

The Windows preview starts through JAGUAR.exe and keeps projects separate from its installation. A project stores its database in a researcher-selected location. Original photographs remain in their source folders.

The workflow follows these steps:

1. A project is created or opened, then source folders are imported. Duplicate contents share one image identity while their paths remain recorded.
2. Settings identify the bundled ExifTool, OCR models, and detector models. CPU processing is available in this preview.
3. Processing runs EXIF extraction, overlay OCR, detection, and reconciliation. Completed stages retain their source evidence; interrupted stages resume from saved checkpoints.
4. Images provides a preview, detection boxes, extracted candidates, and raw evidence. Selected images can receive a targeted processing run.
5. Cameras keeps physical devices separate from deployment labels. Review records conflicts, uncertain results, and reversible human corrections with a reason and actor.
6. Dashboard filters show the available project measurements. Excel export creates a new workbook with data dictionaries, source observations, reviews, processing history, and audit records.

A source label or filename does not establish species identity. No accepted detection remains a review condition because small or distant animals can be missed. EXIF and overlay timestamps can disagree; both observations remain available.

The preview requires fresh-machine testing, real GPU validation, a larger mixed-brand original dataset, and completion of third-party redistribution review before a production release. Installed runtime files should remain together. Uninstallation removes the application; externally stored projects and source photographs remain separate.
