# Windows preview packaging

The preview uses the Python 3.13.17 embedded x64 distribution, PyInstaller 6.16.0 for the launcher, and Inno Setup 6.5.4 for installation. Its build environment contains the pinned application extras plus their installed transitive dependencies. The assembled dependency inventory records the actual versions; it is not yet a fully reproducible release lock.

The build_runtime.py script receives a new destination, the embedded Python ZIP, local OCR model folders, local detector folders, and the complete ExifTool distribution. It copies the application and installed packages into an isolated runtime. Installation sources must exclude original images, project databases, and private metadata.

The installer.iss definition receives SourceDir and OutputDir compiler definitions. Deep dependency paths exceed traditional Windows path limits under the generated development workspace. A temporary short drive mapping to the assembled folder permits compilation; the mapping can be removed after the compiler finishes. Release builds should use a short staging location.

The CPU preview loads one image at a time for inference. Physical CUDA operation, GPU fallback under real failure, and hardware-dependent throughput remain unverified. Local tests do not establish compatibility on clean Windows 10/11 machines.

The package includes application source, the unchanged application license, dependency metadata, original package license files, and model/runtime hashes. Transitive GPL/AGPL and LGPL obligations require a full redistribution review and any required corresponding-source arrangement before external release. The preview is unsigned and remains an internal testing candidate.
